# FindJobs Website

## Files
- `index.html` — all page structures (Home, Find Jobs, Sign In, Create Account, About Us, Contact)
- `style.css` — responsive styling and visual design
- `script.js` — navigation, search, filters, saved jobs, job details modal, and demo forms

## Run it
1. Download and unzip `FindJobs_Website.zip`.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Important
This is a front-end demo. Job listings are sample data. Sign-in, account creation, Google sign-in, job applications, and contact messages are not connected to a backend, so they do not create real accounts, send messages, or submit applications. Images and Google Fonts require an internet connection.
